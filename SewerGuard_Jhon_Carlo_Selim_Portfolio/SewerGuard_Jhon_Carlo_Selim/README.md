# Jhon Carlo Selim — SewerGuard Portfolio

A responsive, animated portfolio concept for **Jhon Carlo Selim** featuring:
- A distinctive dark-green / lime technical visual identity
- Custom illustrated profile avatar (`assets/jhon-avatar.svg`)
- Section-by-section scroll reveal and animated environmental UI
- Interactive SewerGuard workflow explainer
- Clickable learning-toolkit panels
- Responsive mobile navigation and reduced-motion support

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser. No build tools are required.
3. Internet access is needed only for the Google Fonts stylesheet; system fallback fonts are included.

## Before publishing
- Replace `jhon.carlo.selim@example.com` in `index.html` with Jhon Carlo's real public contact email.
- The included avatar is an original stylized illustration, not a real photograph or likeness.
- SewerGuard visuals and sensor status are illustrative concept content, not a live or deployed system.
- Update the About, skills, and project details to match the student's actual background and implementation progress.

## Files
- `index.html` — page content and sections
- `style.css` — responsive layout, transitions, and animations
- `script.js` — navigation, workflow toggle, toolkit interactions, scroll reveals
- `assets/jhon-avatar.svg` — custom vector avatar illustration
